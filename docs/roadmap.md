# 路线图

每个里程碑都要有可验收的数字，没有数字不算完成。

## M0 · 场景与专家轨迹（已完成）

- MuJoCo 场景：WidowX-250 + 桌面 + 自由方块 + 两路 224×224 相机
- 脚本化专家：6-DoF IK，自上而下抓取，抬升 > 6 cm
- 验收：`success=True`，单条 ≤ 600 步
- 状态：`tests/test_sim.py::test_oracle_picks_the_cube` 已覆盖

## M1 · 数据采集（已完成）

- 随机化：方块位置 ±5 cm、桌垫/方块颜色、光照强度、相机机位 ±4 cm
- 采集 200–500 条，存 episode 格式（两路图像 + proprio + 动作 + success）
- 命令：`python -m kitebench.sim.collect --episodes 20 --out episodes`
- 验收：成功率 ≥ 90%，随机种子固定可复现
- 状态：**200/200 成功**（seed 100–299），合计 213 条（含评测用 seed 0–12），约 112 MB，每条 800 步、20 组两路帧

## M2 · 输入层扰动评测（已完成首版）

- 实现 §3 的 12 类图像扰动，全部带 seed
- 对单帧集跑"干净 vs 扰动"的动作漂移，输出 md/csv 表
- 验收：每类扰动 ≥ 5 档，表格含 Δpos / Δrot / grip_flip
- 状态：**46 组配置**跑完，结果见 [`perturb-baseline.md`](perturb-baseline.md)
- 关键结论：固定去噪 seed 后噪声底为 0；模糊（3 px → 70 mm）与遮挡（10% 面积 → 夹爪翻转 31%）最危险，光度变化基本无害

## M3 · 轻量微调（已完成）

- 冻结主干，只训练动作头 + soft prompt
- 输入：M1 的数据集；输出：可加载的 checkpoint
- 验收：闭环成功率相对原始权重提升 ≥ 20 个百分点
- 状态：流程已跑通（特征预计算 → 训练最后 8 个 block → MuJoCo 闭环评测），训练 3 epoch 约 12 分钟
- 已修四个问题：
  1. 夹爪标签存的是手指**位置（米）**而不是 0/1，BCE 学成了常数；改为按**指令值**二值化
  2. 动作块的时间跨度错了：每个 episode 800 个物理步（dt=2 ms），30 步动作块只有 0.06 s，模型学成"近似静止"；改为**控制 20 Hz**（`record_every=25`），30 步覆盖约 1.5 s
  3. **IK 会把仿真留在最后解出的位姿**上，导致每条示教都从"终点"开始、轨迹变成一个闭环；策略忠实地学成了上下往复。已在 `run_pick` 里 IK 之后重新 `reset`
- 另外给示教加了"抬起后侧移"阶段（carry），避免下降段和上升段经过同一批位姿（单帧策略无法区分阶段）
- 现状：**闭环 8/8（100%）**，视频 `out/mujoco/model_pick.mp4`；此前所有 0% 都是执行器问题
- 4. **执行器的 IK 分支问题**：同一末端位姿存在多个解，数值 IK 常解到另一条肘部支路（位置残差仅 0.7 mm，但臂形完全不同，夹爪接近角随之改变）；用**示教流形最近邻**（`demo_ik.py`，27k 个参考点）把末端目标映射到示教使用的关节构型后，闭环从 0/10 变成 8/8
- 关键判据：**回放闸门**——录制关节目标回放示教 `success=True`，IK 回放 `success=False`，证明 0% 属于执行器而非策略
- 另加：`--exec N` 支持滚动时域（只执行 chunk 前 N 步再重规划），默认 10；训练支持 `--init` 续跑


## M5 · 多物体分拣（进行中）

- 场景：3 类物体（红方块 / 蓝圆柱 / 绿方块）+ 2 个分拣台（黄/蓝），指令形如 `put the red cube on the left pad`
- 示教：300 条 pick-and-place（`out/sorting`，300/300 成功；oracle 自身成功率约 8/9，失败样本自动跳过重采）
- 训练：`head_sorting.pt`（8400 个样本，4 epoch）
- 现状：**指令接地已生效**——说"红方块"就移动到红方块，末端距目标 7–25 mm；但**抓取/放置阶段停滞**在悬停位（EE z≈0.114，示教抓取点 z≈0.070），闭环 0/9
- 待查：每类仅 100 条示教是否偏少；30 步动作块是否跨过了"抓取→搬运"两个阶段
- 注意：这是"仿真里 3 类物体分拣"，**不是产线**；传送带/堆叠/多目标不在本版范围

## M6 · 工业外观场景（未通过）

- 场景：`sim/industrial.py`——传送带（带滚筒）、橙色料筐、黄色安全线、深灰地坪；任务区（方块位置、相机、青绿台面）保持不变
- 数据：200 条示教（`out/episodes_ind`，200/200 成功），6000 个样本
- 训练：`head_ind.pt`（4 epoch）+ `head_ind2.pt`（续训 5 epoch，position_loss 0.101 / grip 0.041）
- 结果：**闭环 0/8**（14 个 chunk 仍不够）；回放闸门通过（录制关节回放 `cube_z=0.124`），说明执行链路没问题，是策略没学会新外观
- 结论：**只加背景装饰、任务区不变，也会让策略失效**；200 条示教不足以把新外观学回来。下一轮至少每场景 300–500 条，或让外观随机化和数据一起上（域随机化）
- 该结果本身是鲁棒性证据：外观变化（即使任务几何不变）属于分布外
