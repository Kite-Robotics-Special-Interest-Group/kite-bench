# 路线图

每个里程碑都要有可验收的数字，没有数字不算完成。

## M0 · 场景与专家轨迹（已完成）

- MuJoCo 场景：WidowX-250 + 桌面 + 自由方块 + 两路 224×224 相机
- 脚本化专家：6-DoF IK，自上而下抓取，抬升 > 6 cm
- 验收：`success=True`，单条 ≤ 600 步
- 状态：`tests/test_sim.py::test_oracle_picks_the_cube` 已覆盖

## M1 · 数据采集（已完成）

- 随机化：方块位置 ±5 cm、桌垫/方块颜色、光照强度、相机机位 ±4 cm
- 采集 200–500 条，存 episode 格式（两路图像 + proprio + 动作 + success）
- 命令：`python -m kitebench.sim.collect --episodes 20 --out episodes`
- 验收：成功率 ≥ 90%，随机种子固定可复现
- 状态：**200/200 成功**（seed 100–299），合计 213 条（含评测用 seed 0–12），约 112 MB，每条 800 步、20 组两路帧

## M2 · 输入层扰动评测（已完成首版）

- 实现 §3 的 12 类图像扰动，全部带 seed
- 对单帧集跑"干净 vs 扰动"的动作漂移，输出 md/csv 表
- 验收：每类扰动 ≥ 5 档，表格含 Δpos / Δrot / grip_flip
- 状态：**46 组配置**跑完，结果见 [`perturb-baseline.md`](perturb-baseline.md)
- 关键结论：固定去噪 seed 后噪声底为 0；模糊（3 px → 70 mm）与遮挡（10% 面积 → 夹爪翻转 31%）最危险，光度变化基本无害

## M3 · 轻量微调（进行中）

- 冻结主干，只训练动作头 + soft prompt
- 输入：M1 的数据集；输出：可加载的 checkpoint
- 验收：闭环成功率相对原始权重提升 ≥ 20 个百分点
- 状态：流程已跑通（特征预计算 → 训练最后 8 个 block → MuJoCo 闭环评测），训练 3 epoch 约 12 分钟
- 已修两个数据 bug：
  1. 夹爪标签存的是手指**位置（米）**而不是 0/1，BCE 学成了常数；改为按**指令值**二值化
  2. 动作块的时间跨度错了：每个 episode 800 个物理步（dt=2 ms），30 步动作块只有 0.06 s，模型学成"近似静止"；改为**控制 20 Hz**（`record_every=25`），30 步覆盖约 1.5 s
- 新数据（seed 500–699，200/200 成功，`out/episodes_v2`）已按 20 Hz 采集；`head_v3.pt` 训练到第 2 个 epoch（position_loss 0.40 → 0.32 → 0.22 附近），闭环成功率尚未测


## M4 · 闭环鲁棒性评测

- 同一批初始状态，干净 vs 扰动各跑 N 次
- Unity 侧加 `PERTURB` 命令（光照/材质/机位/遮挡物）
- 验收：给出"扰动族 × 成功率"矩阵，并附动作漂移相关性
